# LGPL source and replacement information

Winsper 1.1.2 includes Qt for Python (PySide6/shiboken6 and Qt 6.11.1), pynput 1.8.2, and pystray 0.19.5 under their respective LGPL terms. Their license texts are included in `licenses/`. These libraries are not covered by Winsper's MIT license.

We offer the complete corresponding source for the exact LGPL library versions shipped in the Winsper 1.1.2 Windows installer, including any Winsper modifications to those libraries, for at least three years after distribution. Request it at **help@winsper.app** and identify the Winsper version. There is no charge beyond any reasonable physical-media delivery cost. The source archive and its checksums are also prepared with `scripts/prepare_lgpl_source_bundle.py` from version-pinned upstream releases. We do not currently modify these libraries.

The bundled Qt DLLs and PySide DLLs are separate files under `Winsper/_internal/PySide6/`; Qt plugins are under its `plugins/` subdirectory. A recipient may replace compatible LGPL libraries there with modified builds, preserving the DLL names and required ABI. The separately packaged Python LGPL modules can be replaced by rebuilding Winsper from its MIT-licensed source with the modified packages installed: install the versions in `requirements-lock.txt`, substitute the modified packages, then run `scripts/build-release.ps1`. The executable does not use code-signature checks to prevent replacement. A modified library must remain binary compatible with the application and other Qt libraries; removing an incompatible DLL may stop Winsper from starting.

The offer covers the library source and build/relinking information, not separately licensed model weights. See `THIRD_PARTY_NOTICES.md` and `release-inventory.json` for the dependency and package inventory. Contact **help@winsper.app** if a replacement path fails; we will provide the version-specific build details needed to exercise LGPL rights.
